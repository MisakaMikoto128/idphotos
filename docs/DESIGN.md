# 视觉规范 — 复古木制

主会话唯一写入。ui-woodcraft 严格执行，**禁止自创色值、禁止改布局结构**。
判定标准：像一个 1930 年代照相馆的木质工作台，不是"给按钮加个木纹贴图"。

## 1. 色卡（Design Token，写成 `lib/ui/theme/tokens.dart`）

| token | 色值 | 用途 |
|---|---|---|
| `woodDark` | `#3E2A1B` | 最外层框体、深色木纹阴影 |
| `woodBase` | `#6B4A2F` | 主背景木纹底色 |
| `woodLight` | `#A9784F` | 木纹高光、边缘倒角 |
| `brass` | `#B08D3F` | 金属件基色（按钮、包角、铰链） |
| `brassHi` | `#E8CE7A` | 金属高光 |
| `brassShadow` | `#6E5320` | 金属暗部 |
| `paper` | `#F4E9D6` | 卡片/照片衬纸、文字区底 |
| `paperEdge` | `#DCCBAE` | 纸张边缘、分隔线 |
| `feltGreen` | `#2F4F3A` | 台面绒布衬底（照片下方） |
| `inkBrown` | `#3A2B1C` | 纸上正文文字 |
| `inkFaded` | `#7A6A55` | 纸上次要文字 |
| `creamText` | `#F0E4CE` | 木头/深色上的文字 |
| `accentRed` | `#8C2B22` | 危险/删除，用旧漆红，不用纯红 |

**禁止**：纯黑 `#000`、纯白 `#FFF`（照片本身除外）、任何饱和度 >70% 的现代蓝紫色、Material 默认紫。

## 2. 材质

| 资源 | 规格 | 说明 |
|---|---|---|
| `assets/textures/wood_tile.png` | 512×512 可平铺 | 核桃木竖直纹理，作背景 `ImageRepeat.repeat` |
| `assets/textures/paper_grain.png` | 512×512 可平铺 | 纸张噪点，`BlendMode.multiply` 叠在 paper 上，opacity 0.12 |
| `assets/textures/brass_corner.png` | 96×96 ×4 方向 | 相框铜包角 |
| `assets/textures/felt.png` | 512×512 可平铺 | 绒布，用于候选区衬底 |

材质由 ui-woodcraft 生成（程序化生成或手绘 CustomPainter 均可，**不得联网下载**，不得使用来源不明的图片）。
优先选择 `CustomPainter` 程序化绘制木纹/纸纹 —— 体积为 0，且可随主题缩放。

## 3. 形态

- 圆角：容器 `6px`，按钮 `4px`。复古家具是小圆角，不要 16px+ 的现代大圆角。
- 边框：所有木质面板用双层边框 —— 外 1px `woodDark`，内 1px `woodLight`（模拟倒角）。
- 阴影：暖色，`Color(0x66241609)`，`blurRadius 8`, `offset (0,3)`。禁止冷灰阴影。
- 金属件：垂直线性渐变 `brassHi → brass → brassShadow`，顶部 1px `brassHi` 高光线。
- 按压反馈：按钮下沉 2px + 阴影收缩，模拟真实按钮，**不要 Material ripple**（`splashFactory: NoSplash`）。

## 4. 字体

- 中文：`Noto Serif SC`（宋体系，复古印刷感）。字重仅用 400 / 700。
- 数字与英文：等宽衬线或 `Courier`-like，用于尺寸标注（如 `25×35mm`），有打字机味。
- 字号阶：`11 / 13 / 15 / 18 / 24`。标题用 24/700，正文 15/400，标注 11/400 + `letterSpacing: 0.5`。
- 字体文件放 `assets/fonts/`，**必须裁剪子集**（中文全量字体 10MB+，只保留 App 内出现的字符）。

## 5. 三段式布局细节

### 区域 A — 上传与框选（占屏 45%）
- 外观：一个木质相框，四角有铜包角。空态时框内是绒布，中央一个铜质"+"和"轻触选择照片"。
- 有图后：图片居中 `contain`，上覆盖一个可拖拽的裁剪框 —— 裁剪框为 2px `brassHi` 实线 + 四角 L 形铜角标 + 三分线（0.3 透明度 `creamText`）。
- 框外区域压暗：`Color(0x99241609)`。
- 四角与四边均可拖拽改变大小，框内可整体拖动。裁剪框**锁定当前 spec 的宽高比**。
- 顶部有一条黄铜"标尺"横条，显示当前规格名与像素尺寸（如 `一寸 · 295×413`），点击弹出规格选择（木质抽屉样式，从下方滑出）。

### 区域 B — 候选结果（占屏 38%）
- 底衬绒布。横向 `ListView`，每张候选是一个小木相框。
- 每个候选：照片 + 下方一小块黄铜铭牌，刻着底色名（`白底` / `蓝底` …）。
- 选中态：相框上浮 4px + 铜边加亮 + 铭牌变亮。未选中略微降低饱和度。
- 生成中：相框内显示纸质占位 + 一个复古"冲洗中"的进度指示（横向推移的木纹刷子或旋转的胶片轮，**不要 Material 圆形转圈**）。

### 区域 C — 保存（占屏 17%）
- 一个宽大的黄铜压花按钮，上面浮雕字"保 存 照 片"。
- 按下时下沉 + 一次短震动（`HapticFeedback.mediumImpact`）。
- 成功后：按钮短暂变为"已保存到相册"，并在其上方飘出一张小纸条动画（300ms）。
- 禁用态：金属变哑光灰褐 `#7A6A55`，不变透明度。

## 6. 动效

- 全部用 `Curves.easeOutCubic`，时长 `180ms`（微交互）/ `320ms`（区域切换）。
- 复古感来自"有重量" —— 元素落下时可有 1 次 2px 的轻微回弹，不要弹簧过冲。
- 禁止：霓虹辉光、玻璃拟态、渐变模糊、粒子特效。

## 7. 深浅色

**不做深色模式。** 木制风格本身即为深色调，强行做浅色版会破坏材质一致性。
`ThemeMode.light` 固定，但整体是暖深色外观。系统深色模式下外观不变。
