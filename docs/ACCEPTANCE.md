# 验收标准（Definition of Done）

**主会话是本文件的唯一写入者。任何 agent 修改本文件 = 立即 FAIL 并终止该阶段。**

全自动模式下没有人工判断，所有 gate 必须是脚本可判的。凡是写不出判定脚本的标准，
一律不作为 gate（可以写进 RUBRIC 交给 visual-critic，但不作为硬门禁）。

判定程序：`tools/gate/gate_G<n>.dart`，退出码 0 = PASS，非 0 = FAIL。
由 `gatekeeper` 执行，**实现类 agent 无权运行也无权修改**。

**计分口径（2026-09-17 主会话裁定，防作弊）**

1. **`unavailable` 一律不计为通过**（P0.1a / P0.3a）。否则一个"永远返回测不出 + 0.0"的实现，在近竖直的锚点上残差天然为 0，会免费通过 P0.1——而这恰恰是把本轮事故重演一遍。
2. **但 `unavailable` 也不是一律有罪**：真正测不出的样本（暗光、闭眼、多人小脸）返回 0 是诚实行为，好过给一个错的角。所以判据落在**条件覆盖率**（P0.1b / P0.3b）：**只要这张图确实需要摆正（\|tilt\| > 1.5°），就必须给出 `pupil` 估计**；不需要摆正的图返回 `unavailable` 无害。
   - 阈值取 **1.5°** 而非拍脑袋的整数：它与 P0.1a 的残差容差**同值**，语义才自洽——"放弃估计"只有在"不转导致的残余本来就能过线"时才是可接受的代价。超过 1.5° 仍放弃，用户拿到的就是一张肉眼可辨的歪照（本次事故是 3.7°），必须记 FAIL 而不是"诚实降级"。若最终证明某类真难样本无法达标，由主会话带证据找用户裁定是否接受**有记录的**缺口，**不许在门禁里悄悄放行**。
3. **P0.2 单独要求 `pupil`**：竖直样本若也允许 `unavailable` 通过，那么"永远放弃"策略就能免费拿下这一项。要求 uprightSynthetic 必须返回 `pupil`，堵住这条通道。
4. **两组判据必须同时成立**：覆盖率逼"不能放弃"、残差逼"不许测错"——放宽门限换取覆盖率会让 P0.1a 的残差爆掉，两者互相牵制。**任何一轮不得只报其中一个数。**
5. 硬判据一律用**成片端到端残余**（口径无关）；`ComposeDiagnostics.straightenDeg` 只作诊断与定位，不作判据。
6. **锚点去重**：qa-batch 报告 12 条倾斜锚点里 `c03`/`c04` 是同一张照片的不同分辨率副本（逐像素 mean\|diff\|=2.74），`c10`/`c11`/`c12` 是同一张五人合影的不同裁切——**实际只覆盖 11 张不同照片**。仍满足"≥8 张"的要求，但报告与判据里的样本数一律按 **11 张不同照片**表述，不得用 12/13 的计数虚增覆盖。
7. **样本不得静默消失**：每轮的锚点/夹具样本数必须与 `out/P0_truth.json` 一致。任何"不可计分"的样本必须**逐条列出并归类**（抠图失效 / 量测失效 / 其他），且在**总数与通过数里同时显式扣除**。
   - **归类为"量测失效"的每一条，必须由 gatekeeper 用与 qa-batch 不同的独立路径复核一次**（如刚体残留配准），并写明复核结论。理由：把真实缺陷归成"量不出来"是这套判据里最容易藏东西的地方——`c08_d+10` 就是现成案例（alpha 干净却自证 unreliable），它的归属会改变违规计数。
   - 判据的**通过率分母一律用扣除后的可见样本数**，并在报告里同时给出原始总数，二者不得只报其一。

## 防作弊条款（全自动模式的核心保护）

以下任一情形直接判定该阶段 **FAIL** 并计入循环预算，不得申辩：

1. 实现类 agent（ml-porting / imaging / ui-woodcraft / release）写入了 `test/`、`tools/gate/`、`docs/ACCEPTANCE.md`、`docs/RUBRIC.md`。
2. gate 脚本的 SHA256 与 gatekeeper 上一轮记录的不一致，且变更不是由 gatekeeper 自己做的。
   （首轮无 `out/hashes_prev.txt` 属正常，直接建立基线，不判 FAIL。）
3. 测试中出现 `skip:`、`@Skip`、注释掉的断言、被放宽的阈值常量。
4. 黄金集被删减、被替换成更容易的图片，或 `test/golden/` 下文件数减少。
5. 通过 catch-all 吞异常来让"0 崩溃"成立（`catch (_) {}` 空实现）。
6. 报告中声称达标但 gate 脚本未实际运行，或运行结果与报告不符。

## 循环预算

每个 gate **最多 3 轮**修复。第 3 轮仍 FAIL：
- 停止该阶段，产出 `out/BLOCKED_G<n>.md`，写清失败项、已尝试的方案、卡在哪
- **不得**降低阈值、**不得**跳过该 gate 继续下一阶段
- 全流程终止，等人工介入
