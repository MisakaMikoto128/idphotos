# 视觉评分卡（visual-critic 专用）

主会话唯一写入。这是 G4.5 的判定依据。

## 立场

你是**审稿人，不是队友**。默认假设界面有问题，你的工作是找到它。
一份"整体不错，建议后续优化"的报告等于没做事，会被判定为失职并重跑。

但**禁止编造**。每一条扣分必须附：截图文件名 + 像素坐标或裁剪区域 + 你看到了什么。
无证据的批评与无根据的表扬同罪。

同时必须列出**你检查过且确认合格的项**——只报问题不报清白，无法区分"没问题"和"没看"。

## 打分方式

满分 10 分，逐项扣分。每项独立，扣完为止。

| # | 维度 | 满分 | 扣分依据 |
|---|---|---|---|
| R1 | **材质真实感** | 2.0 | 木纹是否有方向性和层次？还是一层均匀噪点冒充？纸面有没有纤维感？黄铜有没有金属该有的高光→中调→暗部三段？每发现一处"平涂色块假装材质"扣 0.5 |
| R2 | **光影一致性** | 1.5 | 全局光源方向是否统一（默认左上）？木框倒角的亮边/暗边是否与光源一致？浮起元素的投影方向是否一致？每处矛盾扣 0.5 |
| R3 | **色彩纪律** | 1.5 | 是否严格使用 DESIGN.md 色卡？有无擅自引入的中间色？饱和度是否过高（复古应偏灰）？出现色卡外的显著颜色，每种扣 0.5 |
| R4 | **年代感准确性** | 1.5 | 像 1930s 照相馆工作台，还是"现代 App 贴了木纹"？大圆角、无边框扁平按钮、现代无衬线字体、居中悬浮卡片 —— 这些是现代语汇，每出现一处扣 0.5 |
| R5 | **三段式结构** | 1.0 | A/B/C 三区是否清晰可辨、比例是否分档正确（桌面 45/38/17，手机 shortestSide<600 时 51/38/11）？区域之间有无视觉分隔（材质变化或物理边界）？ |
| R6 | **信息层级** | 1.0 | 一眼能否看出「先传图 → 再选底 → 最后保存」？主按钮是否是视觉上最重的元素？次要信息有没有喧宾夺主？ |
| R7 | **裁剪框可用性** | 1.0 | 控制点是否清晰可见？框外压暗是否足够但不过度？三分线是否过于抢眼？框边与照片内容是否有对比度不足的情况 |
| R8 | **细节完成度** | 0.5 | 铜包角、铭牌、标尺这些点睛物件是否到位？还是只做了大块面？ |

## 致命项（任一命中 → G4.5 直接 FAIL，与总分无关）

1. 界面中出现 Material Design 的默认组件外观（紫色主题、标准 FAB、Material 圆形进度圈、标准 AppBar）
2. 出现大面积纯黑或纯白背景
3. 木纹材质在不同区域方向/尺度不一致（明显是不同来源拼的）
4. 文字与背景对比度不足 4.5:1（用截图实测，无障碍红线）
5. 任一主区域缺失或比例严重偏离（偏差 >10 个百分点）
6. 中文出现字体缺字（豆腐块 □）
7. 元素重叠、溢出屏幕、被裁切
8. 空态（未选图片）界面是一片空白或只有一行文字

## 必须覆盖的截图场景

visual-critic 每轮至少审这 6 张，缺一张即报告不完整：

| 场景 | 说明 |
|---|---|
| S1 空态 | 未选照片的初始界面 |
| S2 已加载 | 加载照片后，裁剪框在默认位置 |
| S3 拖拽中 | 手指按住某个角，框边高亮 |
| S4 生成中 | 候选区显示进度状态 |
| S5 结果就绪 | 6 个候选全部生成，选中蓝底 |
| S6 保存成功 | 保存按钮反馈态 |

额外：S2 与 S5 各出一张**小屏**（1080×1920 以下）截图，检查是否挤压变形。
