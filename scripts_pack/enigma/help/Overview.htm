Enigma Virtual Box

Enigma Virtual Box is files and registry virtualization system that allows to embed multiple files and registry items that your application uses into single executable, keep same file functionality without having embedded files on the disk. Enigma Virtual Box supports any kind of files, Dynamic Link Libraries (*.dll), ActiveX/COM (*.dll, *.ocx), Video/Music (*.avi, *.mp3), Text (*.txt, *doc) etc, and even another executable files (*.exe). It does not extract temporary files on the disk, files emulation process is being done in the process memory only.

How does it work?

Enigma Virtual Box embeds all files into the main executable together with a special loader. The loader executes before the main code of application and hooks some system API functions that allow to read/write files/registry information. When your application tries to access embedded file, the loader recognizes this and returns necessary data. So your packed file works the same as before packing, but without having embedded files on the disk.

Why Enigma Virtual Box?

Enigma Virtual Box is a first freeware application that allows to emulate files and registry systems. Compared with other commercial products that contain same functionality - Enigma Virtual Box has even better performance, stability and quality.

How to start?

Enigma Virtual Box has a very simple interface. Simply select input (main executable of your application) and output files, and files you want to embed. Then click Process button and try resulting exe file!

Does it protect embedded files from being viewed?

Yes, Enigma Virtual Box supports some kind of protection for embedded files, but the strength of such protection is quite low. Apart of Enigma Virtual Box we provide a solution that allows to protect files - Enigma Protector. Enigma Protector has an identical feature - Virtual Box, that works the same as Enigma Virtual Box, but provides also a protection to files. If you wish the embedded files to be protected, we recommend to use Enigma Protector instead.

Where it can be used?

Enigma Virtual Box can be used in any application by any reason, just some ideas:

  • make portable versions of applications, without setup
  • protect files of your application against modifying and illegal copying
  • hide dynamic libraries and it's functionality
  • use ActiveX files without registration and administrator privileges
