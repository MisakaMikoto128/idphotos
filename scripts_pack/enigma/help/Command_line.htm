Command line

Enigma Virtual Box can be used to pack files through the command line. The command line version is located in the installation folder, the file enigmavbconsole.exe.

  • Pack the files using .evb project file, use command enigmavbconsole.exe project.evb
  • Pack the files using .evb project file, but overwrite input and/or output files, use command enigmavbconsole.exe project.evb -input file.exe -output file_boxed.exe
  • Create a package file, use the command enigmavbconsole.exe project.evb package.evb.template output_package.dat
    Where:
    • project.evb Enigma Virtual Box project file
    • package.evb.template package template file created by Package Builder
    • output_package.dat output package file
