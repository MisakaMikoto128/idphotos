# 合规材料（COMPLIANCE）

适用对象：木照 MuZhao（`MuZhao — Offline ID Photo`）。
本文件说明 Play Console 各个政策表单的**预期填写答案**及依据。
所有结论都基于同一事实：**App 不申请 INTERNET 权限、不含任何第三方 SDK、数据全部留在设备本地**。

---

## 1. 数据安全表单（Data Safety）逐项答案

进入路径：Play Console → App content → Data safety。逐题答案如下：

| 问题 | 答案 | 理由 |
|---|---|---|
| 本应用是否收集或共享以下任一类型的数据？ | **否，不收集、不共享** | App 无 INTERNET 权限，技术上无法传输；无统计/广告 SDK |
| 是否收集"个人信息与身份"？ | 否 | 无注册、无账号体系 |
| 是否收集"照片和视频"？ | 否 | 相册读取仅用于用户主动挑选照片，处理后不落盘到 App 专属目录，不离开设备；Data Safety 的"收集"指传出到开发者处，本应用不存在 |
| 是否收集"应用活动/应用信息与性能/设备 ID"？ | 否 | 无任何统计 SDK（gradle 依赖已过 G5.3 检查） |
| 数据是否加密传输？ | 不适用（无可传输数据） | 表单会在选"不收集"后跳过 |
| 用户能否请求删除数据？ | 不适用；如被要求回答：数据不离开设备，卸载即全部清除 | 见隐私政策"本地存储"一节 |
| 是否为儿童设计？ | 不是（目标受众见第 2 节） | — |

**填报口径提醒**：Data Safety 的"收集（collect）"= 数据离开设备到开发者。
用户在设备本地产生并保留的数据不属于"收集"。如实按上表填报即可通过审核。

## 3. 目标受众与年龄段

进入路径：App content → Target audience。

- **目标年龄段：18 岁及以上**（证件照的实际用途——签证、就业、社保报名——均为成人场景）。
  选 18+ 可**同时避开**"是否面向儿童"的后续追问和 Families 政策的额外审核；
- 若同时勾选更低年龄段，会触发 Families 政策审查，**不要勾选**；
- 本应用不含吸引儿童的元素（无卡通角色、无游戏化），与 18+ 定位一致。

## 4. 中国大陆安卓商店的额外要求（重要）

华为、小米、OPPO、vivo、应用宝上架的**硬性前置条件**：

1. **《计算机软件著作权登记证书》**（软著）：
   - 个人可自行向中国版权保护中心申请，或委托代理；
   - 自行申请官方费用约 **250–300 元**（代理另加服务费，总价常见 300–600 元）；
   - 周期 **约 30–60 天**（可加急，费用更高）；
   - 需要材料：源代码前后各 30 页（共 60 页）、操作说明书/用户手册、申请表。
   - **无法自动化，必须由用户线下办理**（详见 CHECKLIST.md）。
2. 各商店均要求**软件著作权人姓名与开发者账号实名一致**，个人账号用个人名义申请软著即可。
3. 部分商店还要求：App 备案（工信部 ICP 备案，2023 年起 App 备案为上架硬要求，需先有域名+服务器或通过云服务商代备案）、
   《隐私政策》URL、免责声明/承诺函。华为还需**华为账号实名认证**。
4. 本应用不申请网络权限，App 备案环节仍建议如实办理（部分渠道按"全离线工具"免审联网资质，但备案本身常为上架前置）。
