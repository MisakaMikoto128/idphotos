# 2026-09-17 第四批（门禁自修：r2 作废的两处输入完整性缺陷）：
#  · tools/gate/gate_P0.dart —— `_roundState()` 原先对 porcelain 行先 `trim()`
#    再交 `_porcelainPath()`。porcelain 格式是 `XY<空格>路径`，未暂存修改的 XY 首字符
#    是空格；trim 掉它之后 `substring(3)` 会切掉路径首字母
#    （` M docs/PITFALLS.md` → `ocs/PITFALLS.md`），`kFreezeExemptPath` 永不命中。
#    后果：只有 PITFALLS 被改（正是要豁免的情形）时 `frozen` 反为 false，整轮作废。
#  · tools/gate/provenance.dart —— `_verifyOne()` 原先从指纹块内部读
#    `roundValid`/`codeStableDuringRun`，但生产侧把它们写在**指纹块的父层**
#    （`codeFingerprint()` 与 `roundVerdict()` 是两个函数、两张表）。

#    → `allBound=false` → **每一轮无条件作废**，与被测代码无关。
